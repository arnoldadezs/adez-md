> 🤖 Available Commands

| Command | Description |
|---------|--------------|
| `.ping` | Check if the bot is alive |
| `.menu` / `.help` | Show the command menu |
| `.alive` | Alive check |
| `.runtime` / `.uptime` | Show how long the bot has been running |
| `.jid` | Get the current chat's ID |
| `.repo` | Link to source code |
| `.owner` | Owner-only test command |
